# inset-app — Activité Pratique Angular 19 (Gestion de produits)

## Lancer
1. `npm install`
2. Backend : votre Spring Boot sur le port 8083 (`@CrossOrigin("*")`), **ou** le backend de test : `node mock-backend.js`
3. `ng serve` puis http://localhost:4200

Inclus : standalone, Bootstrap 5 + Icons, routerLink/router-outlet, @if/@for/@else, ProductService + HttpClient (RxJS), CORS,
et l'exercice 8 (formulaire d'ajout, toggle du badge via PUT, filtre dynamique).
